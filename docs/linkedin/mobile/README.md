# Формат за мобилно приложение

Съдържанието е нарязано на **карти** — всеки блок е подходящ за списък (list / carousel) на малък екран.

## Файлове

| Файл | Употреба |
|------|----------|
| [cards.md](./cards.md) | Четене от хора; копиране на постове по секции |
| [content.mobile.json](./content.mobile.json) | Зареждане в приложение (`fetch` / локален asset) |

## JSON (`content.mobile.json`)

- **`meta`** — версия на формата и език.
- **`cards[]`** — равен списък за UI:
  - `id` — стабилен ключ за навигация / любими.
  - `group` — категория: `pitch`, `site`, `brand`.
  - `title` — заглавие на картата (1 ред).
  - `preview` — много кратък текст за списък (до ~120 знака).
  - `body` — пълен текст за екран с детайл (plain text, `\n` за нов ред).
  - `bullets` — по избор; масив от къси реда за bullet list в приложението.

При нужда добави в приложението поле `pinned` или локален филтър по `group`.

## Препоръки за UI

- Шрифт ≥ 16 px за основен текст; между карти **12–16 px** вертикален интервал.
- `preview` за collapsed state; tap отваря `title` + `body` + `bullets`.
- LinkedIn: от `body` вземи първите 1–2 изречения за hook на мобилен пост.
